# 笔记总览

## 全部笔记

```dataview
TABLE type AS "类型", project AS "项目", category AS "分类", parent AS "模块", status AS "状态", priority AS "优先级", created AS "创建", updated AS "更新", summary AS "主要内容"
FROM "obsidian note"
WHERE codex_dataview = true AND type != "dashboard"
SORT project ASC, category ASC, created DESC
```

## 按项目分组

```dataview
TABLE length(rows) AS "数量", rows.file.link AS "笔记"
FROM "obsidian note"
WHERE codex_dataview = true AND type != "dashboard"
GROUP BY project
SORT project ASC
```

## 最近创建


## 关系最密集

```dataview
TABLE project AS "项目", category AS "分类", summary AS "主要内容", file.outlinks AS "指向", file.inlinks AS "被引用"
FROM "obsidian note"
WHERE codex_dataview = true AND type != "dashboard" AND (length(file.outlinks) > 0 OR length(file.inlinks) > 0)
SORT (length(file.outlinks) + length(file.inlinks)) DESC
LIMIT 50
```

## 进行中 / 高优先级

