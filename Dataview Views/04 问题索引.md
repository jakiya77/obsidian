# 问题索引

## 可继续推进的问题 / 想法

```dataview
TABLE type AS "类型", project AS "项目", category AS "分类", priority AS "优先级", created AS "创建", updated AS "更新", summary AS "主要内容"
FROM "obsidian note"
WHERE codex_dataview = true AND type != "dashboard" AND (type = "idea" OR status = "active" OR priority = "high")
SORT project ASC, priority ASC, updated DESC
```

## 建议转成 ChatGPT Project 的主题

```dataview
TABLE length(rows) AS "数量", rows.file.link AS "相关笔记"
FROM "obsidian note"
WHERE codex_dataview = true AND type != "dashboard" AND priority = "high"
GROUP BY project
SORT length(rows) DESC
```
