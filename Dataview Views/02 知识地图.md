# 知识地图

## 知识库总表

```dataview
TABLE project AS "项目", category AS "分类", parent AS "模块", created AS "创建", summary AS "主要内容", file.outlinks AS "关联"
FROM "obsidian note/knowledge"
WHERE codex_dataview = true
SORT category ASC, parent ASC, file.name ASC
```

## 按分类聚合

```dataview
TABLE length(rows) AS "数量", rows.file.link AS "笔记"
FROM "obsidian note/knowledge"
WHERE codex_dataview = true
GROUP BY category
SORT category ASC
```

## 数学与优化

```dataview
TABLE category AS "分类", parent AS "模块", summary AS "主要内容", file.outlinks AS "关联"
FROM "obsidian note/knowledge"
WHERE codex_dataview = true AND (project = "数学与优化基础" OR category = "Math" OR category = "Optimum")
SORT category ASC, file.name ASC
```
