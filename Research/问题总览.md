# 问题总览

## 使用规则
- 每个具体问题建一个独立笔记，放在 `obsidian note/Research/Questions/项目名/`。
- 每个长对话结束后，用 `ChatGPT长对话索引模板` 生成索引，再把其中真正需要追踪的问题拆成 `问题索引模板`。
- `status` 建议只用 `open`、`doing`、`blocked`、`done`。
- `priority_rank` 建议用 `3`、`2`、`1`，分别对应 high、medium、low，方便 Dataview 排序。

## 未解决问题
```dataview
TABLE id AS ID, project AS 项目, parent AS 父主题, status AS 状态, priority AS 优先级, created AS 创建时间
FROM "obsidian note/Research/Questions"
WHERE type = "question" AND status != "done"
SORT priority_rank DESC, created DESC
```

## 高优先级问题
```dataview
TABLE id AS ID, project AS 项目, parent AS 父主题, status AS 状态, created AS 创建时间
FROM "obsidian note/Research/Questions"
WHERE type = "question" AND priority = "high" AND status != "done"
SORT created DESC
```

## 已完成问题
```dataview
TABLE id AS ID, project AS 项目, parent AS 父主题, created AS 创建时间
FROM "obsidian note/Research/Questions"
WHERE type = "question" AND status = "done"
SORT created DESC
```

## ChatGPT 长对话索引
```dataview
TABLE project AS 项目, status AS 状态, created AS 创建时间
FROM "obsidian note/Research"
WHERE type = "conversation-index"
SORT created DESC
```
