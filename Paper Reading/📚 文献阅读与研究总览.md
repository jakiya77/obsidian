## 🚀 正在阅读 (Reading)

```dataview
TABLE without id file.link AS "文献标题", authors AS "作者", year AS "年份", publicationTitle AS "期刊/会议" FROM #📝文献笔记 WHERE status = "reading" SORT year DESC
````

## ⏳ 待阅读清单 (To-Read)

已经导入库中、等待后续精读或泛读的文献池。


```dataview
TABLE without id
  file.link AS "文献标题",
  authors AS "作者",
  year AS "年份"
FROM #📝文献笔记
WHERE status = "to-read" or status = "" or !status
SORT file.mtime DESC
```

## 🕒 最近导入文献 (Recent Additions)

最近同步到 Obsidian 的最新研究成果。

```dataview
TABLE without id file.link AS "文献标题", status AS "阅读状态", year AS "年份" FROM #📝文献笔记 SORT file.mtime DESC LIMIT 5
```
