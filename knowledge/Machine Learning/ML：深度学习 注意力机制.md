**[RF-D9-A] 你其实已经认识它的一半：加权求和**

假设有三个历史时刻的信息 $u_1$,$u_2$,$u_3$，你想把它们汇总成一个结果：

$c=0.1u_1+0.3u_2+0.6u_3.$

这很好理解：越近的信息占比越大。

但如果系数是我们事先固定的，那么**无论输入是什么，三个时刻始终占 10%、30%、60%。**

**[RF-D9-B] 注意力的关键：权重随当前输入变化**

注意力机制希望做到：

- 看到一组历史数据时，认为最近时刻最有参考价值，给出 [0.1,0.3,0.6][0.1,0.3,0.6]；
    
- 换一组历史数据时，认为中间时刻更有参考价值，给出 [0.2,0.7,0.1][0.2,0.7,0.1]。
    

汇总仍然是加权求和：

$\boxed{ c=a_1v_1+a_2v_2+a_3v_3, \qquad (a_1,a_2,a_3)=f_{\theta}(U) }$

这里：

- $U$：当前输入的整组历史信息；
    
- $f_{\theta}$：根据这组信息计算权重的规则；
    
- $\theta$：通过训练学到的参数。
    

**Q、K 那套计算，就是实现$f_{\theta}(U)$ 的一种方式。** V 则是参与最终加权求和的信息。

**[RF-D9-C] 训练参数和计算注意力权重是两件事**

这是最容易混淆的地方：

|量|如何得到|训练结束后，换一组输入会怎样？|
|---|---|---|
|WQ,WK,WVW_Q,W_K,W_V|在训练中通过预测误差更新|通常保持不变|
|注意力权重 MM|用当前输入和上述矩阵计算|会随输入变化|

例如，训练时网络预测未来波束，预测错了，就通过反向传播调整这些矩阵。多次训练后，它逐渐学会怎样变换输入、怎样分配注意力，才能帮助预测。

**所以，“注意力”不是人为告诉网络要关注哪个时刻，而是让网络学会一套规则，在每次看到数据时计算该怎样加权。** 至于学到的权重是否对应某个明确的物理机制，还需要额外分析，不能直接把它等同于信道相关性。


**可以。我们把输入从 [1,2][1,2] 换成 [2,1][2,1]，直接看三种结构里哪些数变了。** 下面的参数都是为了演示而假设的，代表“已经训练完的参数”。

**[1.1-F2-A] CNN：乘输入的系数不变**

假设一个一维卷积核是 [0.2,0.8][0.2,0.8]，只看一个窗口，省略偏置和激活：

y=0.2x1+0.8x2.y=0.2x_1+0.8x_2.

| 输入    | 计算                      | 输出  |
| ----- | ----------------------- | --- |
| [1,2] | $0.2\times1+0.8\times2$ | 1.8 |
| [2,1] | $0.2\times2+0.8\times1$ | 1.2 |

输入变了，输出变了，但**始终是第一个位置乘 0.2，第二个位置乘 0.8。**

---

**[1.1-F2-B] RNN：更新规则不变，传递的状态变了**

为了方便手算，用一个简化的线性递归例子：

$h_t=0.5h_{t-1}+x_t,\qquad h_0=0.$

意思是：每一步把旧状态保留一半，再加上当前输入。实际普通 RNN 通常还会加非线性激活。

|输入序列|第一步|第二步|
|---|---|---|
|[1,2][1,2]|h1=0.5×0+1=1h_1=0.5\times0+1=1|h2=0.5×1+2=2.5h_2=0.5\times1+2=2.5|
|[2,1][2,1]|h1=0.5×0+2=2h_1=0.5\times0+2=2|h2=0.5×2+1=2h_2=0.5\times2+1=2|

**状态从 11 变成 22，但“旧状态乘 0.5，再加当前输入”这条规则没变。**

---

**[1.1-F2-C] 注意力：连“分别乘多少”也根据输入重新算**

假设我们只计算**第二个位置的注意力输出**，采用最简单的标量设计：

q2=x2,k1=x1,k2=x2,v1=x1,v2=x2.q_2=x_2,\qquad k_1=x_1,\quad k_2=x_2,\qquad v_1=x_1,\quad v_2=x_2.

也就是固定 WQ=WK=WV=1W_Q=W_K=W_V=1，它们始终不变。

先拿第二个位置的 q2q_2，分别和两个位置的 key 相乘，得到分数，再用 softmax 转成总和为 1 的权重：

|步骤|输入 [1,2][1,2]|输入 [2,1][2,1]|
|---|---|---|
|第二个位置的 query|q2=2q_2=2|q2=1q_2=1|
|匹配分数 [q2k1,q2k2][q_2k_1,q_2k_2]|[2,4][2,4]|[2,1][2,1]|
|softmax 得到的权重|[0.119,0.881][0.119,0.881]|[0.731,0.269][0.731,0.269]|
|加权汇总|0.119×1+0.881×20.119\times1+0.881\times2|0.731×2+0.269×10.731\times2+0.269\times1|
|输出|1.8811.881|1.7311.731|

你看，**输入一换，乘在两个位置上的系数也从 [0.119,0.881][0.119,0.881] 变成了 [0.731,0.269][0.731,0.269]。**

这里没有重新训练。变化是因为：

> **固定的 WQ,WKW_Q,W_K 处理不同输入，得到不同的 Q、K，于是算出了不同的注意力权重。**

这就是前面那张表里“参数不变，但注意力权重随输入改变”的具体意思。

这次直接对比**三段可以执行的算法**，统一输入，再只改一个数，检查差异发生在哪一步。

输入分别为：

XA=[1,2,1],XB=[4,2,1].X_A=[1,2,1],\qquad X_B=[4,2,1].

**只把第一个数从 1 改成 4，其他数保持不变。三种算法都计算第 3 个位置的输出。** 下面的参数人为设定，整个过程中保持不变。

**[1.1-F2-A] CNN：直接使用固定卷积核**

取一个长度为 3 的卷积核：

w=[0.2,  0.3,  0.5].w=[0.2,\;0.3,\;0.5].

算法就是：

```matlab
w = [0.2, 0.3, 0.5];    % 固定参数
z = sum(w .* x);        % 输入分别乘对应系数，再相加
y = max(0, z);          % ReLU：负数截成0
```

实际计算：

|输入|卷积计算|输出|
|---|---|---|
|XA=[1,2,1]X_A=[1,2,1]|0.2×1+0.3×2+0.5×10.2\times1+0.3\times2+0.5\times1|1.31.3|
|XB=[4,2,1]X_B=[4,2,1]|0.2×4+0.3×2+0.5×10.2\times4+0.3\times2+0.5\times1|1.91.9|

**改变输入后，仍然使用同一个 [0.2,0.3,0.5][0.2,0.3,0.5]。算法没有先计算一组新的加权系数。**

**[1.1-F2-B] RNN：逐个读输入，每一步更新状态**

取一个标量 RNN：

ht=ReLU⁡(0.5ht−1+xt),h0=0.h_t=\operatorname{ReLU}(0.5h_{t-1}+x_t),\qquad h_0=0.

算法是：

```matlab
h = 0;                     % 初始状态

for t = 1:3
    h = max(0, 0.5*h + x(t));
end

y = h;                     % 第3步的状态作为输出
```

实际计算：

|步骤|输入 XA=[1,2,1]X_A=[1,2,1]|输入 XB=[4,2,1]X_B=[4,2,1]|
|---|---|---|
|第 1 步|h1=0.5×0+1=1h_1=0.5\times0+1=1|h1=0.5×0+4=4h_1=0.5\times0+4=4|
|第 2 步|h2=0.5×1+2=2.5h_2=0.5\times1+2=2.5|h2=0.5×4+2=4h_2=0.5\times4+2=4|
|第 3 步|h3=0.5×2.5+1=2.25h_3=0.5\times2.5+1=2.25|h3=0.5×4+1=3h_3=0.5\times4+1=3|

这里第一个数改变后，影响沿着 **h1h_1、h2h_2、h3h_3** 传递。

**RNN 每一步使用固定的状态更新规则，但送进下一步的状态会改变。**

**[1.1-F2-C] 自注意力：先根据输入生成系数，再用系数加权**

现在看 Transformer 中的单头自注意力。把每个位置的特征简化为一个数，固定：

WQ=WK=WV=1.W_Q=W_K=W_V=1.

只计算第 3 个位置的输出，算法是：

```matlab
q = 1 * x(3);              % 第3个位置的 query
k = 1 * x;                 % 三个位置的 key
v = 1 * x;                 % 三个位置的 value

score = q * k;             % 第一步：分别计算匹配分数
a = exp(score);
a = a / sum(a);            % 第二步：把分数转成注意力权重

y = sum(a .* v);           % 第三步：用刚算出的权重汇总
```

因为两组输入的 x3x_3 都是 1，**query 始终是 q=1q=1**。变化来自第一个 key：

|计算步骤|输入 XA=[1,2,1]X_A=[1,2,1]|输入 XB=[4,2,1]X_B=[4,2,1]|
|---|---|---|
|匹配分数 qkqk|[1,2,1][1,2,1]|[4,2,1][4,2,1]|
|指数运算|[e1,e2,e1][e^1,e^2,e^1]|[e4,e2,e1][e^4,e^2,e^1]|
|除以总和，得到权重 aa|[0.212,0.576,0.212][0.212,0.576,0.212]|[0.844,0.114,0.042][0.844,0.114,0.042]|
|用权重汇总 vv|0.212×1+0.576×2+0.212×10.212\times1+0.576\times2+0.212\times1|0.844×4+0.114×2+0.042×10.844\times4+0.114\times2+0.042\times1|
|输出，约为|1.5761.576|3.6463.646|

**最值得盯住的是第二个输入：它一直等于 2，但乘在它前面的注意力权重，从 0.576 变成了 0.114。**

因为第一个位置的匹配分数变大，经过归一化，分配给其他位置的比例也跟着改变了。

**[1.1-F2-D] 差异具体在哪几行算法？**

|结构|核心算法|加权系数从哪里来？|
|---|---|---|
|**CNN**|`sum(w .* x)`|直接使用训练得到的卷积核 `w`|
|**RNN**|循环执行 `h = ReLU(0.5*h + x(t))`|使用训练得到的状态更新参数，逐步传递 `h`|
|**自注意力**|`score = q*k` → `a = softmax(score)` → `sum(a.*v)`|**先用当前输入算出 `a`，再拿 `a` 加权**|

这里说明的是三种基础运算的区别。实际 CNN、RNN 也能通过非线性、门控等方式产生随输入变化的响应；**这个自注意力算法的特征，是明确计算“查询位置与各个来源位置的匹配分数”，再生成跨位置的汇总权重。**
