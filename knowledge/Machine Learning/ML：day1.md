## 1. python 的向量乘法和matlab对应关系

| 数学表达式     | Python语法             | Matlab 语法       |
| --------- | -------------------- | --------------- |
| 共轭内积      | np.vdot(w, x)        | w.' * x         |
| 不取共轭的内积   | np.dot(w, x)         | w .* x          |
| 逐元素乘法     | w * x                | w .* x          |
| 先逐元素乘，再求和 | np.sum(np.conj(w)*x) | sum(conj(w).*x) |
#### 具体计算例子：复数向量的四种运算

假设有一个三阵元接收系统，权向量和接收信号分别为：

- **权向量**：w = [1, −j, 2]ᵀ
    
- **接收信号**：x = [1+j, 2−j, 2j]ᵀ
    
- 其中 j² = −1。
    

**（1）共轭内积：

首先对权向量取共轭：

w* = [1, j, 2]ᵀ

然后逐项相乘并求和：

y = (1)(1+j) + (j)(2−j) + (2)(2j)

= (1+j) + (1+2j) + 4j

**= 2+7j**

输出是一个复数标量。

**（2）普通内积：
这里不对权向量取共轭，直接相乘求和：

z = (1)(1+j) + (−j)(2−j) + (2)(2j)

= (1+j) + (−1−2j) + 4j

**= 3j**

输出也是一个复数标量，但与共轭内积的结果不同。

**（3）逐元素乘法：

三个位置上的元素分别相乘：

- 第一个元素：1 × (1+j) = 1+j
    
- 第二个元素：(−j) × (2−j) = −1−2j
    
- 第三个元素：2 × 2j = 4j
    

因此得到：

**[1+j, −1−2j, 4j]ᵀ**

注意：结果依然是一个三元素向量，并没有进行求和。

**（4）先共轭、逐元素相乘，再求和：** 就是`np.vdot(w, x)`

首先得到逐元素乘法结果：

[1+j, 1+2j, 4j]ᵀ

然后将三个元素求和：

(1+j) + (1+2j) + 4j

**= 2+7j**

所以这个表达式与 `np.vdot(w, x)` 在本例中结果相同。


| 运算         | Python                 | 计算结果               |
| ---------- | ---------------------- | ------------------ |
| 共轭内积       | `np.vdot(w,x)`         | `2+7j`             |
| 普通内积       | `np.dot(w,x)`          | `3j`               |
| 逐元素乘法      | `w*x`                  | `[1+j, -1-2j, 4j]` |
| 共轭逐元素乘法再求和 | `np.sum(np.conj(w)*x)` | `2+7j`             |



**核心结论：**

- `vdot`：第一个向量先取共轭，再相乘求和。
    
- `dot`：不取共轭，直接相乘求和。
    
- `*`：NumPy 数组的逐元素乘法，不自动求和。
    
- `sum(conj(w)*x)`：显式实现共轭内积。
    

**注意维度：** 本例的 MATLAB 向量按 3×1 列向量定义，而 Python 中 `np.array([1, -1j, 2])` 创建的是形状为 `(3,)` 的一维数组。两者数值运算可以对应，但严格来说维度表示并不完全相同。
