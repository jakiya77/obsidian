## TL;DR
[[Telecom：傅立叶变化]]
**核心主线**

  

$$\boxed{\text{多径} \rightarrow \text{延迟副本叠加} \rightarrow \text{线性卷积} \rightarrow \text{加 CP} \rightarrow \text{有效区间呈现循环卷积} \rightarrow \text{FFT} \rightarrow \text{频域逐点乘法}}$$

**关键概念**

  

$$\boxed{\text{卷积 = 多个延迟版本的加权叠加}}$$
$$\boxed{\text{循环卷积 = 超出边界的部分从另一端绕回来}}$$
$$\boxed{\text{CP = 把当前 OFDM 符号尾部复制到前面，使多径在有效区间内满足“循环”结构}}$$

### ### 一、整体知识框架

- **多径信道**
    
    - **1. 为什么产生卷积？**
        
        - 不同路径 = 不同延迟副本
            
    - **2. 什么是线性卷积？**
        
        - 序列边界之外补 0
            
    - **3. 什么是循环卷积？**
        
        - 序列首尾相连，超出边界就绕回来
            
    - **4. CP 有什么作用？**
        
        - 将 OFDM 有效符号内的线性卷积转化成循环卷积
            
    - **5. 为什么需要 CP 足够长？**
        
        - 必须覆盖最大有效多径时延扩展
            
    - **6. 为什么循环卷积 + FFT 很重要？**
        
        - FFT 后变成逐子载波乘法：$Y[k] = H[k]X[k]$



### 二、为什么通信系统里会出现卷积？

假设发送信号是：

  

$$x[n]$$

信道有两条路径。

  

**路径 1：主径**

不延迟，增益为 $1$：



$$x[n]$$

**路径 2：反射径**

延迟一个采样，增益为 $0.5$：

  

$$0.5x[n-1]$$

那么接收信号：

  

$$\boxed{y[n]=x[n]+0.5x[n-1]}$$

可以画成：

  

Plaintext

```
               ┌──────── ×1 ────────┐
x[n] ──────────┤                    │
               │                    ├──→ y[n]
               └─ delay 1 ─ ×0.5 ──┘
```

所以从物理角度：

  

$$\boxed{\text{卷积本质就是：一个信号的多个延迟副本经过不同增益后叠加}}$$

信道：

  

$$h=[1,0.5]$$

其实就是在告诉你：

  

- delay 0：权重 $1$
    
      
    
- delay 1：权重 $0.5$
    
      
    

### 三、什么是线性卷积？

取一个最简单的例子：

  

$$x=[1,2,3,4]$$

信道：

  

$$h=[1,0.5]$$

因此：

  

$$y[n]=x[n]+0.5x[n-1]$$

在线性卷积里，序列不存在的位置默认：

  

$$\boxed{x[n]=0}$$

**逐点计算**

  

$n=0$

  

$$y[0]=x[0]+0.5x[-1]$$

由于：

  

$$x[-1]=0$$

所以：

  

$$y[0]=1$$

$n=1$

  

$$y[1] = x[1]+0.5x[0] = 2+0.5 = 2.5$$

$n=2$

  

$$y[2] = 3+0.5\times2 = 4$$

$n=3$

  

$$y[3] = 4+0.5\times3 = 5.5$$

$n=4$

虽然原始信号已经结束，但是延迟路径中的 $x[3]$ 还没有结束：

  

$$y[4] = 0+0.5\times4 = 2$$

最终：

  

$$\boxed{y_{\text{linear}} = [1,\ 2.5,\ 4,\ 5.5,\ 2]}$$

### 四、为什么线性卷积输出会变长？

因为：

  

$$x=[1,2,3,4]$$

经过 delay 后，还有一个“尾巴”。可以理解成：

  

原始：

  

Plaintext

```
1    2    3    4
```

延迟一拍 ×0.5：

  

Plaintext

```
     0.5   1   1.5   2
```

最后那个：

  

$$2$$

已经跑到了原序列之外。

  

所以长度：

  

$$\boxed{N_x+N_h-1}$$

这里：

  

$$4+2-1=5$$

### 五、什么是循环卷积？

循环卷积最大的变化只有一个：**序列不再被认为是一条直线，而是假设它首尾相连。**

  

原来：

  

Plaintext

```
1 → 2 → 3 → 4
```

循环以后：

  

Plaintext

```
      1
    ↗   ↘
   4     2
    ↖   ↙
      3
```

所以：

  

$$x[-1]$$

不再等于 0，而是：

  

$$\boxed{x[-1]=x[3]=4}$$

### 六、同样的例子做循环卷积

仍然：

  

$$x=[1,2,3,4]$$

$$h=[1,0.5]$$

而：

  

$$y[n]=x[n]+0.5x[n-1]$$

$n=0$

循环情况下：

  

$$x[-1]=x[3]=4$$

所以：

  

$$y[0] = 1+0.5\times4 = 3$$

其他位置：

  

$$y[1]=2+0.5\times1=2.5$$

$$y[2]=3+0.5\times2=4$$

$$y[3]=4+0.5\times3=5.5$$

因此：

  

$$\boxed{y_{\text{circular}} = [3,\ 2.5,\ 4,\ 5.5]}$$

### 七、线性卷积和循环卷积到底差在哪？

把结果放在一起：

  

**线性卷积**

  

$$[1,\ 2.5,\ 4,\ 5.5,\ \boxed 2]$$

**循环卷积**

最后那个 $2$ 不放在末尾，而是：

  

Plaintext

```
[1, 2.5, 4, 5.5, 2]
 ↑               │
 └───────────────┘
      绕回来
```

所以：

  

$$1+2=3$$

得到：

  

$$\boxed{[3,\ 2.5,\ 4,\ 5.5]}$$

因此可以非常直观地记：

  

$$\boxed{\text{循环卷积 = 线性卷积超出长度 N 的尾巴，绕回前面相加}}$$

### 八、CP 为什么会和循环卷积联系起来？

假设当前一个 OFDM 时域符号：

  

$$[x_0,x_1,x_2,x_3]$$

信道：

  

$$h=[1,0.5]$$

第二条路径 delay = 1 sample。

  

**1. 没有 CP**

假设前一个 OFDM symbol 是：

  

$$[a_0,a_1,a_2,a_3]$$

实际连续发送：

  

Plaintext

```
前一个symbol       当前symbol
a0 a1 a2 a3 | x0 x1 x2 x3
```

对于当前 symbol 的第一个采样：

  

$$x_0$$

延迟路径需要一个：

  

$$x[-1]$$

但当前 symbol 前面没有数据。所以它实际拿到的是：

  

$$a_3$$

于是：

  

$$\boxed{y_0=x_0+0.5a_3}$$

这意味着：

  

$$\boxed{\text{上一个 OFDM symbol 污染当前 symbol}}$$

这就是 ISI。

  

### 九、加入 CP 后发生什么？

CP：

  

$$\boxed{\text{Cyclic Prefix}}$$

循环前缀。

  

假设 CP 长度为 1。就把当前 OFDM symbol 的最后一个采样：

  

$$x_3$$

复制到前面：

  

$$\boxed{[x_3\ \vert{}\ x_0,x_1,x_2,x_3]}$$

于是：

  

Plaintext

```
CP      有效OFDM symbol
 ↓
x3 | x0 x1 x2 x3
```

现在 delay = 1 的第二条路径需要前一个 sample 时：

  

$$x[-1]$$

得到的是：

  

$$\boxed{x_3}$$

而不是上一 symbol 的：

  

$$a_3$$

于是：

  

$$y_0=x_0+0.5x_3$$

其他采样：

  

$$y_1=x_1+0.5x_0$$

$$y_2=x_2+0.5x_1$$

$$y_3=x_3+0.5x_2$$

你会发现：

  

$$\boxed{\begin{aligned}y_0&=x_0+0.5x_3\\ y_1&=x_1+0.5x_0\\ y_2&=x_2+0.5x_1\\ y_3&=x_3+0.5x_2\end{aligned}}$$

正好就是：

  

$$\boxed{\text{循环卷积}}$$

### 十、所以 CP 的真正作用是什么？

不要记成：CP 消除了多径。

这是不准确的。多径还在。

  

真正作用是：

  

$$\boxed{\text{CP让多径造成的跨 OFDM symbol 影响落在 CP 中}}$$

接收机随后：

  

$$\boxed{\text{直接把 CP 丢掉}}$$

留下的有效 OFDM symbol 就不会受到上一 symbol 的污染。

所以：

  

$$\boxed{\text{CP主要用于防止 OFDM symbol 之间的 ISI}}$$

### 十一、CP 必须多长？

你之前已经抓住这个问题了：如果 delay 比 CP 还长怎么办？

  

答案：

  

$$\boxed{\text{CP 就挡不住了}}$$

假设：

  

$$L_{\rm CP}=1$$

只能保护 1 sample 的 delay。

  

如果信道：

  

$$h=[1,0,0.5]$$

意味着最大 delay：

  

$$2\text{ samples}$$

那 CP 只有：

  

$$x_3$$

但 delay 2 需要：

  

$$x[-2]$$

CP 中没有。于是会继续跑进：

  

$$\boxed{\text{上一个 OFDM symbol}}$$

产生 residual ISI。

  

所以需要：

  

$$\boxed{L_{\rm CP}\geq L_h-1}$$

更物理地说：

  

$$\boxed{T_{\rm CP} \geq \text{最大有效多径时延扩展}}$$

### 十二、注意：是时延扩展，不是总传播时间

例如：

主径：

  

$$\tau_1=100\ \mu s$$

反射径：

  

$$\tau_2=100.5\ \mu s$$

虽然信号整体传播了：

  

$$100\ \mu s$$

但 CP 真正关心的是：

  

$$\boxed{\tau_2-\tau_1=0.5\ \mu s}$$

因为整体到达晚了多少可以通过同步解决。

真正导致：

  

$$\text{symbol 展宽}$$

的是多径之间的：

  

$$\boxed{\text{相对 delay}}$$

### 十三、为什么循环卷积一做 FFT 就变成乘法？

这是下一层核心。

  

时域中：

  

$$y=x\circledast h$$

DFT 后：

  

$$\boxed{Y[k]=X[k]H[k]}$$

为什么？

最底层原因其实只有一个：

  

$$\boxed{\text{复指数经过 delay 后，仍然是原来的频率，只多一个相位因子}}$$

假设：

  

$$x[n]=e^{j\omega n}$$

延迟 $l$ 个 sample：

  

$$x[n-l] = e^{j\omega(n-l)}$$

拆开：

  

$$\boxed{x[n-l] = e^{-j\omega l} e^{j\omega n}}$$

其中：

  

$$e^{-j\omega l}$$

只是一个复数。

  

所以：

**delay 不会把频率 $\omega$ 变成另一个频率，只会改变它的幅度/相位。**

  

### 十四、多径信道对一个纯频率会怎样？

例如：

  

$$h=[1,0.5]$$

所以：

  

$$y[n] = x[n]+0.5x[n-1]$$

如果：

  

$$x[n]=e^{j\omega n}$$

那么：

  

$$x[n-1] = e^{-j\omega}x[n]$$

因此：

  

$$y[n] = x[n] + 0.5e^{-j\omega}x[n]$$

于是：

  

$$\boxed{y[n] = \left(1+0.5e^{-j\omega}\right)x[n]}$$

定义：

  

$$\boxed{H(\omega) = 1+0.5e^{-j\omega}}$$

所以：

  

$$\boxed{y[n]=H(\omega)x[n]}$$

这说明：

**对一个确定频率，复杂的多径最终只相当于乘了一个复数 $H(\omega)$。**

  

### 十五、那 DFT/FFT 在干什么？

DFT 就是在把复杂信号表示成很多不同的复指数频率。

  

比如 $N$ 点 DFT 使用：

  

$$\omega_k=\frac{2\pi k}{N}$$

这些离散频率。

  

于是每个频率分别经过信道：

  

$$X[0] \rightarrow H[0]X[0]$$

$$X[1] \rightarrow H[1]X[1]$$

……

  

所以：

  

$$\boxed{Y[k]=H[k]X[k]}$$

### 十六、用 4 点 DFT 看更直观

4 点 DFT：

  

$$N=4$$

单位圆相位增量：

  

$$\frac{2\pi}{4} = \frac{\pi}{2} = 90^\circ$$

四个 DFT basis：

  

**$k=0$**

每个 sample 转：

  

$$0^\circ$$

对应：

  

$$[1,1,1,1]$$

**$k=1$**

每个 sample 转：

  

$$90^\circ$$

一个周期：

  

$$1,\ -j,\ -1,\ j$$

**$k=2$**

每个 sample 转：

  

$$180^\circ$$

所以：

  

$$1,-1,1,-1$$

**$k=3$**

相当于负频率：

  

$$-\frac{\pi}{2}$$

因此：

  

$$\boxed{N\text{ 点 DFT可以理解为测试 N 种离散的复平面旋转速度}}$$

但要注意：

  

$$\boxed{\text{单位圆上的位置 = phase}}$$

而：

  

$$\boxed{\text{每个 sample 沿圆旋转多少 = frequency}}$$

### 十七、为什么 FFT 后 OFDM 特别好处理？

时域里：

  

$$y[n] = h_0x[n] + h_1x[n-1] + h_2x[n-2]$$

一个输出和多个输入 sample 耦合。很麻烦：

  

Plaintext

```
x[n]   ─┐
x[n-1] ─┼──→ y[n]
x[n-2] ─┘
```

经过：

  

$$\text{CP}+\text{FFT}$$

之后：

  

Plaintext

```
X[0] ──× H[0]──→ Y[0]
X[1] ──× H[1]──→ Y[1]
X[2] ──× H[2]──→ Y[2]
X[3] ──× H[3]──→ Y[3]
```

每个子载波互相独立。所以均衡特别简单：

  

$$\boxed{\hat X[k] = \frac{Y[k]}{H[k]}}$$

或者更一般：

  

$$\hat X[k] = W[k]Y[k]$$

### 十八、整个 OFDM 多径处理过程

最后把整条链串起来：
Plaintext

```
发送 OFDM symbol
        ↓
      加 CP
        ↓
无线多径信道
        ↓
多个 delay 副本叠加
        ↓
本来是线性卷积
        ↓
CP 足够长
        ↓
有效 OFDM symbol 内表现为循环卷积
        ↓
去掉 CP
        ↓
       FFT
        ↓
循环卷积被对角化
        ↓
Y[k] = H[k]X[k]
        ↓
每个子载波单独均衡
        ↓
恢复 X[k]
```

### 十九、最终记忆版

① 卷积

  

$$\boxed{\text{卷积 = 延迟副本的加权叠加}}$$

② 线性卷积

  

$$\boxed{\text{边界以外补0}}$$

③ 循环卷积

  

$$\boxed{\text{超过边界以后从另一端绕回来}}$$

④ CP

  

$$\boxed{\text{把 OFDM 尾部复制到前面，构造首尾相接条件}}$$

并且要求：

  

$$\boxed{T_{\rm CP}\geq\text{最大有效多径时延扩展}}$$

⑤ FFT

  

$$\boxed{\text{把循环卷积变成每个频率上的独立乘法}}$$

最终：

  

$$\boxed{Y[k]=H[k]X[k]}$$

### 二十、最核心的一条逻辑

这其实就是 OFDM 为什么特别适合宽带多径信道 的底层数学逻辑：

$$\boxed{\begin{array}{c}\text{多径} \\ \downarrow\\ \text{延迟副本叠加} \\ \downarrow\\ \text{线性卷积} \\ \downarrow\quad\text{CP} \\ \text{循环卷积} \\ \downarrow\quad\text{FFT} \\ \text{逐子载波乘法} \\ \downarrow\\ Y[k]=H[k]X[k]\end{array}}$$
