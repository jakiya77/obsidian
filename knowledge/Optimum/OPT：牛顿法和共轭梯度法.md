> [!abstract] TLDR
> 在无约束非线性优化问题 $\min_{x \in \mathbb{R}^n} f(x)$ 中，**牛顿法（Newton's Method）** 与 **共轭梯度法（Conjugate Gradient Method, CG）** 代表了两种不同的进化路线。
> - **牛顿法** 是经典的**二阶方法**，追求极致的单步收敛速度，利用局部曲率直接一步到位，但付出了高昂的计算代价。
> - **共轭梯度法** 是**一阶方法中的常胜将军**，通过巧妙构造正交的共轭方向，仅用一阶梯度的计算代价，实现了逼近二阶方法的收敛效果。
> 
> 本篇笔记将从数学机理、几何直观、复杂度剖析以及二者的融合（Newton-CG）方案进行全方位梳理，特别适合具备最优性条件基础的深度复习。


## 1. 数学机理与迭代机制

### 1.1 牛顿法（Newton's Method）
牛顿法的核心思想是**局部二次近似**。假设目标函数 $f(x)$ 二阶连续可导，在当前迭代点 $x_k$ 处对其进行二阶泰勒展开：

$$f(x_k + \Delta x) \approx f(x_k) + \nabla f(x_k)^T \Delta x + \frac{1}{2} \Delta x^T \nabla^2 f(x_k) \Delta x$$

其中 $H_k = \nabla^2 f(x_k)$ 为海森矩阵（Hessian Matrix）。为了求该近似二次函数的极小值点，令其对 $\Delta x$ 的导数为 $0$：

$$\nabla f(x_k) + H_k \Delta x = 0 \implies \Delta x = -H_k^{-1} \nabla f(x_k)$$

> [!important] 迭代公式
> $$x_{k+1} = x_k - H_k^{-1} \nabla f(x_k)$$
> **几何直观**：在当前点拟合一个二次抛物面，下一步直接跳到该抛物面的理论极小值点。

---

### 1.2 共轭梯度法（Conjugate Gradient Method）
共轭梯度法最初是为了求解大型对称正定线性方程组 $Ax = b$（等价于最小化凸二次函数 $f(x) = \frac{1}{2}x^T Ax - b^Tx$）而设计的，后被推广到非线性优化。

它的核心思想是：**沿一组关于正定矩阵 $A$ 共轭的方向进行一维搜索。**
两个方向 $d_i$ 和 $d_j$ 关于 $A$ 共轭是指满足：

$$d_i^T A d_j = 0 \quad (i \neq j)$$

> [!tip] 迭代公式（以非线性CG的FR方法为例）
> 1. **搜索方向**：$d_k = -g_k + \beta_k d_{k-1}$ （其中 $g_k = \nabla f(x_k)$）
> 2. **权重系数（Fletcher-Reeves）**：$\beta_k = \frac{\|g_k\|^2}{\|g_{k-1}\|^2}$
> 3. **步长更新**：$x_{k+1} = x_k + \alpha_k d_k$ （$\alpha_k$ 通过精确或不精确一维搜索确定）
> 
> **几何直观**：在消除当前方向的误差时，通过引入 $\beta_k$，确保新方向不会破坏之前所有步已经优化好的方向上的成果。

## 2. 核心区别对比

| 维度 | 牛顿法 (Newton's Method) | 共轭梯度法 (Conjugate Gradient) |
| :--- | :--- | :--- |
| **导数阶数** | 二阶（依赖梯度 $\nabla f$ 及海森矩阵 $H$） | 一阶（仅依赖梯度 $\nabla f$） |
| **收敛速度** | 局部**二阶收敛** (Quadratic) | **超线性收敛** (Superlinear) |
| **二次型表现** | 对于严格凸二次型，**1 步**收敛 | 对于 $n$ 维严格凸二次型，最多 **$n$ 步**收敛 |
| **单步时间复杂度** | $\mathcal{O}(n^3)$（用于解线性方程组 $H_k d_k = -g_k$） | $\mathcal{O}(n)$ 或 $\mathcal{O}(m)$ （仅涉及向量内积与矩阵-向量乘法） |
| **空间复杂度** | $\mathcal{O}(n^2)$（需要显式存储海森矩阵 $H_k$） | $\mathcal{O}(n)$（仅需存储当前梯度和前一步的搜索方向） |
| **对病态矩阵的敏感度**| 不敏感。二阶信息天然矫正了空间的伸缩（预条件化） | 较敏感。条件数很大时需引入预条件子（PCG） |
| **鲁棒性与限制** | 要求 $H_k$ 正定。若非正定，可能走向极大值点或鞍点 | 针对非二次型函数， $\beta_k$ 的选择需满足强Wolfe条件以确保下降性 |

## 3. 深刻联系与理论本质

### 3.1 二次型问题下的殊途同归
最优化理论的经典结论是：**任何平滑非线性函数在极小值点局部都可以近似看作正定二次型。**
针对二次型 $f(x) = \frac{1}{2}x^T A x - b^T x$，两者的内在逻辑可以这样理解：

- **牛顿法**：选择**直接暴力通关**。它通过显式计算并对 $A$ 求逆（$x^* = A^{-1}b$），等同于将物理空间做一个线性变换，把“扁平狭长”的等高线椭圆瞬间变成标准的圆，因此 $1$ 步直达。
- **共轭梯度法**：选择**子空间迭代逐步蚕食**。它虽然不计算 $A^{-1}$，但在第 $k$ 步时，它能保证在由前 $k$ 个梯度张成的克雷洛夫子空间（Krylov Subspace） $\mathcal{K}_k(A, g_0) = \text{span}\{g_0, Ag_0, A^2g_0, \dots, A^{k-1}g_0\}$ 中找到**全局最优解**。因此，它在第 $n$ 步时，子空间扩张到全空间 $\mathbb{R}^n$，必然精确撞到最优解。

> [!important] 理论升华：CG 隐式利用了二阶信息
> 为什么CG作为一阶方法能吊打最速下降法（梯度下降）？
> 关键在于，共轭方向的构造公式 $d_k = -g_k + \beta_k d_{k-1}$ 中，$\beta_k$ 的推导本质上利用了矩阵 $A$ 的正交不变性。CG 不需要显式写出 $A$ 矩阵，它通过**连续两次迭代的梯度差**，隐式地抓取了函数曲率（即海森矩阵的信息）。

## 4. 算法融合：截断牛顿法 (Newton-CG)

在面对大规模工业优化问题（如 $n > 10^5$）时：
- 纯牛顿法由于要存储 $\mathcal{O}(n^2)$ 的海森矩阵并进行 $\mathcal{O}(n^3)$ 的求逆，彻底瘫痪；
- 纯共轭梯度法虽然内存省，但收敛步数可能较多。

为了取长补短，现代数值最优化演化出了 **Newton-CG（又称截断牛顿法 Truncated Newton）** 算法。

### 4.1 核心思想
牛顿法的外层迭代需要求解牛顿方程：
$$H_k d_k = -g_k$$
这本质上是一个对称正定（假设 $H_k \succ 0$）的线性方程组 $Ax = b$！
既然共轭梯度法（Linear CG）是求解大型对称正定线性方程组的王牌，那我们**在牛顿法的内层循环中，用 CG 算法来近似求解这个牛顿方向 $d_k$**。

### 4.2 算法双层架构

```
┌───────────────────────────────────────────────────────────┐
│ 外层循环：牛顿法框架 (迭代计算 x_k)                        │
│ 1. 计算当前点一阶梯度 g_k                                  │
│                                                           │
│   ┌───────────────────────────────────────────────────┐   │
│   │ 内层循环：线性共轭梯度法 (CG)                      │   │
│   │ 目的：近似求解 H_k * d_k = -g_k                    │   │
│   │ 优势：不需要显式写出 H_k，只需提供 Hessian-vector │   │
│   │       乘法算子 (H_k * v)，内存消耗降为 O(n)         │   │
│   │ 截断条件：达到精度要求 或 发现负曲率 (H_k 非正定) │   │
│   └───────────────────────────────────────────────────┘   │
│                                                           │
│ 2. 获得近似牛顿方向 d_k                                    │
│ 3. 线搜索确定步长 alpha_k，更新 x_{k+1} = x_k + alpha_k*d_k│
└───────────────────────────────────────────────────────────┘
```

> [!tip] 为什么要叫“截断” (Truncated)？
> 当内层 CG 迭代求解 $H_k d_k = -g_k$ 时，我们不需要完全等到 CG 收敛到极致精度（那需要 $n$ 步）。只要当前解满足：
> $$\|H_k d_k + g_k\| \le \eta_k \|g_k\| \quad (\text{其中 } \eta_k = \min(0.5, \sqrt{\|g_k\|}))$$
> 就可以强行“截断”并跳出内层循环。在远离最优解时，粗略估计方向即可；在接近最优解时，$\|g_k\|$ 变小，截断精度自动变高，完美保持了牛顿法的局部二阶收敛特性。

## 5.算法步骤

### 4.1 经典牛顿法 (Newton's Method) 算法步骤

在实际应用中，通常使用的是带线搜索的**阻尼牛顿法（Damped Newton Method）**，以保证全局收敛性。纯牛顿法的步长固定为 $1$。

1. **初始化**：给定初始点 $x_0$ 和精度阈值 $\epsilon > 0$。令迭代步数 $k = 0$。
    
2. **计算梯度与海森矩阵**：在当前点 $x_k$ 处，计算目标函数的一阶梯度 $g_k = \nabla f(x_k)$ 和二阶海森矩阵 $H_k = \nabla^2 f(x_k)$。
    
3. **收敛检验**：如果梯度的范数 $\|g_k\| < \epsilon$，则算法停止，输出 $x_k$ 作为近似最优解。
    
4. **求解搜索方向（牛顿方程）**：求解如下线性方程组，得到搜索方向 $d_k$：
    
    $$H_k d_k = -g_k$$
    
    _(注：这里要求 $H_k$ 必须是正定矩阵，否则可能无法解出有效的下降方向)_
    
5. **一维搜索（可选但必要）**：沿着方向 $d_k$ 进行线搜索，寻找合适的步长 $\alpha_k > 0$，使得函数值充分下降。常用的准则是满足 Armijo 准则或 Wolfe 准则。
    
    _(注：如果是纯牛顿法，则直接令 $\alpha_k = 1$)_
    
6. **更新迭代点**：执行更新公式：
    
    $$x_{k+1} = x_k + \alpha_k d_k$$
    
7. **迭代递增**：令 $k = k + 1$，返回**步骤 2** 继续循环。
    

---

### 4.2 非线性共轭梯度法 (Nonlinear CG) 算法步骤

共轭梯度法在处理非线性问题时，有多种变体（主要区别在于计算权重系数 $\beta$ 的公式不同）。以下步骤以最经典的 **Fletcher-Reeves (FR) 共轭梯度法**为例。

1. **初始化**：给定初始点 $x_0$ 和精度阈值 $\epsilon > 0$。计算初始梯度 $g_0 = \nabla f(x_0)$。
    
    令初始搜索方向等于负梯度方向：$d_0 = -g_0$。
    
    令迭代步数 $k = 0$。
    
2. **收敛检验**：如果当前梯度的范数 $\|g_k\| < \epsilon$，则算法停止，输出 $x_k$ 为最优解。
    
3. **一维线搜索**：沿着当前方向 $d_k$ 寻找步长 $\alpha_k$，使得：
    
    $$\alpha_k = \arg\min_{\alpha > 0} f(x_k + \alpha d_k)$$
    
    _(注：CG 对线搜索的要求极高，通常要求满足**强 Wolfe 条件**，以确保共轭性和下降性)_
    
4. **更新迭代点**：执行更新公式：
    
    $$x_{k+1} = x_k + \alpha_k d_k$$
    
5. **计算新梯度**：在新的迭代点计算一阶梯度 $g_{k+1} = \nabla f(x_{k+1})$。
    
6. **计算共轭权重参数 $\beta_{k+1}$**：利用前一步和当前步的梯度信息，计算方向组合系数（此处为 FR 公式）：
    
    $$\beta_{k+1} = \frac{\|g_{k+1}\|^2}{\|g_k\|^2}$$
    
    _(注：其他著名公式包括 PR 公式 $\beta_{k+1} = \frac{g_{k+1}^T(g_{k+1}-g_k)}{\|g_k\|^2}$ 等)_
    
7. **构造新搜索方向**：将负梯度方向与历史搜索方向进行线性组合，生成新的共轭方向：
    
    $$d_{k+1} = -g_{k+1} + \beta_{k+1} d_k$$
    
8. **算法重启（可选防御机制）**：如果迭代步数 $k+1$ 是变量维度 $n$ 的整数倍，或者发现当前方向不再是下降方向（即 $g_{k+1}^T d_{k+1} \ge 0$），则将搜索方向重置为负梯度方向：$d_{k+1} = -g_{k+1}$。
    
9. **迭代递增**：令 $k = k + 1$，返回**步骤 2** 继续循环。
## 6. 总结 工程选型


1. **小规模、高度非线性、算力充沛** $\implies$ **牛顿法（或加上拟牛顿法如 BFGS/L-BFGS）**。
2. **大规模、稀疏矩阵、内存受限（如三维重建、大型物理仿真、二次规划）** $\implies$ **预条件共轭梯度法 (PCG)**。
3. **大规模、非线性、需要极高精度** $\implies$ **Newton-CG (截断牛顿法)**。
