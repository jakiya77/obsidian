### fadls_select.m 头部注释
```matlab
% =========================================================================
% Complexity of heuristic mode:
% For the n-th selected antenna, each candidate evaluation costs O(n)
% because only mean(H), mean(G), vector norms, and h^H g are computed.
% With B candidate positions, the greedy selection cost is O(B N^2).
%
% Complexity of direct-SINR mode (FADLS-screened SINR):
% For the n-th selected antenna, each candidate evaluation solves an
% n-by-n linear system and costs approximately O(n^3).
% With B candidate positions, the greedy selection cost is O(B N^4).
% =========================================================================
